# FIRS E-Invoice API Documentation

This repository contains the documentation for the FIRS E-Invoice API, structured for README.io integration.

## Repository Structure

The documentation is organized in the `.readme/` directory with the following structure:

```
.readme/
├── README.md              # Main documentation index
├── sync.json              # README.io sync configuration
├── overview.md            # API overview and features
├── getting-started.md     # Getting started guide
├── authentication.md      # Authentication endpoints
├── qr-code-generation.md # QR code generation API
├── invoice-management.md  # Invoice management endpoints
├── erp-integration.md    # ERP integration guide
├── error-handling.md     # Error handling reference
├── best-practices.md     # Best practices and code examples
├── support.md            # Support information
└── changelog.md          # API changelog
```

## README.io Integration

This repository is configured for README.io sync. The `sync.json` file defines the page structure and categories:

- **Introduction**: Overview, Getting Started
- **API Reference**: Authentication, QR Code Generation, Invoice Management
- **Guides**: ERP Integration, Error Handling, Best Practices
- **Resources**: Support, Changelog

## Source Documentation

The original consolidated documentation is available in `README_IO_DOCUMENTATION.md` for reference.

## Usage

When connected to README.io, the platform will automatically sync the markdown files from the `.readme/` directory based on the structure defined in `sync.json`.
